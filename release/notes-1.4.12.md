## Прошивка 1.4.12 / 190 + Hub 1.4.27 — безопасное OTA и самовосстановление

### Самовосстановление модуля

- **Ранний boot-guard**: счётчик неудачных загрузок нового образа хранится в RTC-памяти и проверяется в самом начале `setup()`, до Wi-Fi/BLE/LittleFS. Если новый образ не подтвердился за 3 загрузки, вызывается штатный откат IDF на предыдущую прошивку. Это работает даже если приложение падает до инициализации OTA.
- **Откат по IDF**: `CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE` уже включён; новый образ помечается как `PENDING_VERIFY` и подтверждается только после 30–45 секунд работы и восстановления связи с кластером.
- **Ошибка OTA больше не подвешивает модуль**: при таймауте, ошибке проверки подписи/SHA или применения патча обновление отменяется, загрузочный раздел не переключается, модуль продолжает работать на старой прошивке и возвращается в kMesh.
- **Возобновление после сбоя**: битовая карта принятых чанков сохраняется в NVS каждые 128 чанков. После watchdog/перезагрузки модуль продолжает с того же места, а не качает образ заново. Прогресс привязан к слоту, `patch_id` и целевой сборке.
- **Меньше нагрузки на watchdog**: при записи полного образа mesh-задача уступает планировщику каждые 16 чанков.

### Экономия эфира и LoRa

- После полной сборки образа приёмник отправляет источнику сигнал «готово», и шлюз прекращает раздачу, не занимая эфир лишние минуты.
- **По LoRa полный образ больше не раздаётся**. Полные образы и большие патчи ( > 192 КБ ) идут только по ESP-NOW.
- Для LoRa разрешены только небольшие дельта-патчи. Если патча нет или он слишком большой, обновление по LoRa не запускается — модуль остаётся на старой прошивке, а не висит часами в эфире.
- Патчи сохраняются только если они хотя бы на 40% меньше полного образа — бесполезные «патчи» размером с образ отбрасываются.

### Hub

- Hub **1.4.27**: проверка размера патча для LoRa, полный образ только ESP-NOW, ограничение генерации патчей двумя предыдущими сборками.
- Восстановлены корректные образы сборки **189** для всех чипов/вариантов, чтобы дельта-патчи 189 → 190 считались от той прошивки, которая реально стоит на модулях.

### Важно для дальних модулей

Для OTA по LoRa нужен **небольшой** дельта-патч. Если модуль стоит на сборке, для которой патча нет (например, 185 → 190), обновить его по LoRa нельзя: нужен ESP-NOW, USB или промежуточная сборка, для которой есть патч. Это сделано специально, чтобы не занимать LoRa-эфир на часы и не оставлять модуль без связи.
