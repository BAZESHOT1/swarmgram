# Klinto 1.10.12 — стабильное автоподключение модуля

Дата: 16 ноября 2026 года.

## Почему модуль «пропадал»

После перехода прошивки на `hardwareId = esp32-<MAC12>` сохранённая запись
модуля содержала старый `hardwareId = esp32-<node8>`. Автоподключение
сравнивало их, считало модуль «чужим» и **закрывало уже установленное
соединение**. Отсюда цикл: скан → connect → INFO → close → скан.

Теперь модуль сверяется по `mod6` из BLE-имени `KL-<prefix>-<mod6>` — это
последние 3 байта MAC, они совпадают с `hardwareId` при любой истории записи.

## Прочее

- Если модуль уже подключён системой и не рекламируется, приложение находит
  его через `connectedDevices()`/известные устройства (в том числе без фильтра
  по сервису).
- При разрыве BLE освобождается GATT-соединение, чтобы модуль снова
  рекламировался.
- HELLO отправляется раз в 15 секунд, поэтому `gateway`/`queue` остаются
  актуальными.
