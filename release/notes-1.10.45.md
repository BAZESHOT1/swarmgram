# Klinto 1.10.45 — приложение никогда не рвёт связь с носимым модулем

- Убран сторож «тишины»: прежде при молчании модуля 45 с приложение само разрывало BLE-соединение.
- Неудача/таймаут записи больше не закрывает соединение (раньше при долгой записи вызывался разрыв и переподключение).
- Подписка на notify модуля остаётся всегда: модуль может быть единственным источником входящих пакетов (mesh/шлюз).
  Android при долгой тишине пересоздаёт подписку, сначала создавая новую и только потом снимая старую.
- Разрыв происходит только по событию системы (модуль выключен/вне зоны) или по действию пользователя.
- Прошивка 174 (прошита на ESP32-носимый и C3-шлюз): Hub-подтверждение «сохранено», без LOG-кадров в BLE.
