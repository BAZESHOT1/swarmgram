# Klinto 1.10.0 — OLED-дизайн чатов и парящий док

Дата: 14 ноября 2026 года.

## Главное

- Новый **OLED-дизайн** экрана чатов: фон `#000000`, графитовые поверхности
  `#161618` / `#1C1C1E`, тонкая обводка `rgba(255,255,255,0.08)`.
- **Многоступенчатый поиск** на Reanimated: заголовок «Чаты» и кнопка «+»
  сжимаются за 200 мс, капсула поиска растягивается на всю ширину,
  при вводе открывается полноэкранный оверлей с `FlashList` категорий.
- **Карточка чата по макету**: squircle-аватар `54x54` (`borderRadius: 14`,
  `expo-image` + `recyclingKey`), онлайн-индикатор `12x12 #30D158`
  с чёрной обводкой, превью в две строки, время `13px`, счётчик
  непрочитанных `#2C2C2E 22x22` и закладка закрепления.
- **Нижний парящий док** `60x30`: вкладки «Чаты» / «Настройки», активная
  подложка `#2C2C2E`, аватар профиля в скруглённом квадрате.
- **Динамические боковые капсулы**: слева `Соединение... / Синхронизация...`
  только при необходимости, справа капсула модуля `KMesh_v1`
  (зелёная точка, число узлов, `⇄ #FFD60A`) с переходом на `/modules`.

## Производительность

- `FlashList` и переиспользование ячеек сохранены.
- Все переходы и пружины — на `react-native-reanimated`.
- Свайп-жесты — `react-native-gesture-handler`.
- Аватары и медиа — `expo-image` с memory-disk кэшем.
- Полноэкранный поиск скрывает док через внешний стор `chatSearchState`
  (`useSyncExternalStore`), без лишних перерисовок списка.

## Платформы

- iOS: `BlurView` в доке, сборка подтверждена GitHub Actions.
- Android: плотная поверхность `#161618`, сборка подтверждена GitHub Actions.
- Web: `backdropFilter` для матового стекла, `expo export -p web` без ошибок.
