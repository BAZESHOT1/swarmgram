# OLED-дизайн экрана чатов и нижнего дока

## Палитра

- Фон экрана: `#000000`.
- Поверхности: `#161618` / `#1C1C1E`, обводка `1px rgba(255,255,255,0.08)`.
- Разделители: `StyleSheet.hairlineWidth`, `rgba(255,255,255,0.08)`.
- Активный элемент дока: `#2C2C2E`.
- Онлайн-индикатор: `#30D158` с чёрной обводкой `2px`.
- Непрочитанные: капсула `#2C2C2E`, высота `22`, радиус `11`.

## Хедер

- Заголовок «Чаты»: `28px`, `700`, `#FFFFFF`.
- Поиск: капсула `borderRadius: 20`, `#161618`, плейсхолдер по центру.
- Кнопка «+»: `38x38`, круглая, `#161618`.

Анимация поиска полностью на Reanimated:
- заголовок и «+» сжимаются до ширины `0`, `opacity: 0`, `scale: 0.85`;
- строка поиска растягивается, появляется `✕`;
- при вводе открывается полноэкранный оверлей с FlashList категорий;
- закрытие возвращает всё в исходное состояние.

Нижний док скрывается через `chatSearchState` (useSyncExternalStore), поэтому
оверлей не перекрывается навигацией.

## Карточка чата

- Аватар: `54x54`, `borderRadius: 14`, `expo-image` с `recyclingKey`.
- Имя: `17px`, `600`, белое.
- Превью: `14px`, `#8E8E93`, до 2 строк.
- Время: `13px`, `#8E8E93`.
- Справа снизу: непрочитанные и закладка закреплённого чата.
- Разделитель начинается с отступа `66` (аватар + gap).

## Стекло и закреплённые чаты

- Поиск, кнопка «+» и нижний док используют общий компонент `Glass`
  (`src/components/Glass.tsx`): `BlurView` на iOS/Android и CSS
  `backdrop-filter` на web.
- Размытие обрезается по радиусу контейнера (`overflow: hidden`),
  поэтому под скруглённым доком не появляется квадратная подложка.
- Заливка кнопок шапки — `rgba(255,255,255,0.12)`, док — `0.08`.
- Закреплённые чаты получают фон `rgba(255,255,255,0.07)`; пока список
  находится в самом верху, тот же фон получает шапка, образуя единую
  серую поверхность. При скролле шапка плавно возвращается к прозрачности.
- Ширина поиска увеличена примерно на 5% (боковые зоны шапки `88` вместо
  `92`), плейсхолдер центрирован: иконка лупы не занимает место, пока
  поиск не раскрыт.
- Боковые капсулы дока появляются пружинной анимацией Reanimated
  (`SideCapsule`): сдвиг из стороны + плавное увеличение прозрачности.

## Нижний док

- Парящая капсула `height: 60`, `borderRadius: 30`, `#161618`.
- Вкладки «Чаты» и «Настройки», активная подложка `#2C2C2E`.
- Слева динамическая капсула `Соединение... / Синхронизация...`.
- Справа капсула модуля KMesh_v1: зелёная точка, число узлов, `⇄ #FFD60A`.
- На узких экранах (`<390`, `<360`) ширина дока и капсул уменьшается,
  текст сжимается через `flexShrink`, элементы не наезжают друг на друга.
- На iOS используется `BlurView`, на web — `backdropFilter`, на Android —
  плотный `#161618`.
