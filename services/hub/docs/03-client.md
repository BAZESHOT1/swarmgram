# Клиент (Expo / React Native)

Один кодовый базис для web, iOS и Android: `client/`. Маршрутизация — expo-router (`client/app`), данные — TanStack Query + собственный слой `client/src/data`.

## Структура `client/app`

| Путь | Экран |
| --- | --- |
| `(auth)/login, register, verify` | Вход, регистрация, подтверждение почты |
| `(app)/chats` | Список чатов + поиск (в т. ч. поиск через kMesh без Hub) |
| `(app)/chat/[id]` | Переписка |
| `(app)/user/[username]` | Профиль пользователя |
| `(app)/settings*` | Настройки: внешний вид, безопасность, уведомления, сеть, о приложении, журнал приложения |
| `(app)/modules` | Страница «Модули»: подключённый модуль, карта кластера, список «Мои модули» |
| `(app)/modules-add` | «Добавить модуль»: прошитый или прошить новый (мастер) |
| `(app)/admin` | Админка: аккаунты, узлы, модули, чаты, жалобы, отладка, **«База данных»** (документация) |
| `(app)/firmware`, `nodes` | Расширенная прошивка и узлы хранения |

## Слои `client/src`

| Каталог | Содержимое |
| --- | --- |
| `data/api.ts` | Типизированный REST-клиент Hub (`/v1/...`), single-flight refresh токена |
| `data/queries.ts` | Хуки TanStack Query (чаты, модули, передачи, мутации) |
| `data/messaging.ts` | Отправка/получение: шифрование, выбор транспорта (HTTP, mesh, outbox) |
| `data/cache.ts`, `db.ts` | Кэш в памяти и локальная БД (sqlite / kv) |
| `crypto/core.ts` | AES-GCM, ECDH P-256, HKDF, подписи, ключи чатов; `crypto/storage.ts` — защищённое kv |
| `modules/*` | Транспорт к модулям: `ble.native.ts` (react-native-ble-plx), `transport.web.ts` (Web Serial/Bluetooth), `ModuleProvider` — единая точка подключения |
| `kmesh/v1/*` | Клиентский стек kMesh_v1 (кадры, RPC, ключи пар, relay-sync, поиск) |
| `mesh/*` | Кластерная осведомлённость, офлайн-синхронизация, outbox |
| `components/modules` | Карточки, мастер прошивки (`SimpleFirmwareWizard`), карта кластера (`ClusterMap`) |
| `components/admin` | Отладка модулей, панель документации |
| `debug/appLog.ts` | Перехват console для просмотра логов в «О приложении → Журнал» |

## ModuleProvider

`ModuleProvider` владеет подключением к модулю (BLE/USB), разбирает INFO-кадры (`nodeId`, роль, `firmware` как `<версия>/<сборка>`, `battery`, `gateway`, `name`, соседи `nb`), восстанавливает связь по последнему модулю и подписывается на события.

Принципы:

- Приложение **никогда не рвёт BLE** из-за тишины или ошибок записи — всегда остаётся подписанным.
- Чужие и свободные модули **не подключаются автоматически** и не вызывают уведомлений; автоподключение — только к своим (префикс владельца в BLE-имени или MAC из «Моих модулей»).
- Если интернета нет, а есть модуль, отправка идёт через kMesh (см. `05-kmesh.md`).

## Страница «Модули»

1. Шапка: «назад» и «+».
2. «Подключённый модуль» — только при активном подключении.
3. «Карта кластера» (`ClusterMap`): корень — последний подключённый носимый модуль; данные — INFO-соседи самого модуля и `GET /v1/kmesh/v1/topology`; узлы по слоям (мой / соседи / кластер / соседние кластеры), линии — прямая связь, цвет по RSSI, пунктир — LoRa, глобус — шлюз с Hub. `nodeId` считается из MAC так же, как в прошивке (FNV-1a).
4. «Мои модули»: компактные раскрытые карточки (название, роль, RSSI, заряд, MAC, версия прошивки, бейдж «обновление», переименование, обновление, Wi‑Fi шлюза, удаление). Удалять можно и модули без данных — привязка по MAC снимается `DELETE /v1/kmesh/v1/modules/:mac`.
5. Бейдж «обновление» сравнивает `<версия>/<сборка>` модуля с `firmware_releases`: обновление есть только если номер сборки на сервере больше.

## Мастер прошивки (`SimpleFirmwareWizard`)

Шаги: тип → интерфейсы (LoRa + ESP-NOW / ESP-NOW / LoRa) → плата (esp32 Lite, C3, C5, C6, S3) → название и пин делителя батареи (пусто — без батареи) → LoRa-чип (SX1262, SX1278, SX1276, LR2021) и пины → Wi‑Fi (для шлюза) → сборка → прошивка по USB (esptool) → итог (MAC, BLE-имя, версия, пины). После записи вызывается `kmeshV1ClaimModule` — привязка по MAC и UUID владельца.

## Сборки

- Web: `expo export -p web`.
- iOS: GitHub Actions `ios-unsigned.yml` → IPA без подписи.
- Android: `android-apk.yml`.
- Версия приложения — `client/app.json`, `package.json`, `src/version.ts` (менять вместе).
